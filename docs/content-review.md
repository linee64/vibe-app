## 4. Проверено и оставлено без изменений (выборочно)

- Vite: только переменные с префиксом `VITE_` попадают в клиентский код (u4-4 #2, u4-6 #4) — https://vite.dev/guide/env-and-mode
- Tailwind: брейкпоинты sm 640 / md 768 / lg 1024 / xl 1280 px (u2-4 #2) — https://tailwindcss.com/docs/responsive-design
- Vercel: импорт репозитория → переменные окружения → Deploy (u5-2 #2); бесплатный HTTPS (u5-3 #4)
- supabase-js: ошибки возвращаются в `{ error }`, а не выбрасываются, поэтому их нужно проверять (u4-5 #2)
- Баги в коде: `i <= length` → NaN (u1-6 #4), `fetch` без await (u3-3 #2), `u => { u.name }` (u3-3 #5), `user_id = user_id` (u4-2 #4)

## 5. Что стоит перепроверять

- Supabase планирует отключить legacy-ключи anon/service_role к концу 2026 года: после этого упоминания «раньше anon / service_role»
  можно оставить как историческую справку, а пример с `VITE_SUPABASE_SERVICE_ROLE_KEY` (u4-6 #4) заменить на `VITE_SUPABASE_SECRET_KEY`.
- Названия режимов в ИИ-редакторах (Plan Mode, чекпоинты) меняются часто — сверять раз в квартал.
