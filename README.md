# Вайбик — прототип

Фронтенд-прототип обучающего приложения («уроки по 5 минут») про **вайб-кодинг**:
как создавать софт, общаясь с ИИ (Cursor, Claude, ChatGPT, v0, Lovable, Bolt).

Стек: Vite 8 + React 19 + TypeScript + Tailwind CSS v4. Бэкенд по желанию: Supabase (аккаунты, прогресс),
DeepSeek (ИИ-проверка домашек), Polar (оплата Pro), функции `/api` на Vercel. **Без настроек всё работает
в браузере в демо-режиме.** Как подключить всё по-настоящему — пошагово в **[SETUP.md](SETUP.md)**.

## Быстрый старт (запуск у себя на компьютере)

Работает одинаково на **Windows, macOS и Linux**.

### 1. Что нужно установить

**Node.js** версии **20.19 или новее** (ветка 20) либо **22.12 или новее** — это минимальные версии,
которые поддерживает Vite 8 (`"engines": { "node": "^20.19.0 || >=22.12.0" }`).
Рекомендуем просто поставить **актуальную LTS-версию** (на октябрь 2026 — Node.js 24 LTS)
с официального сайта: **https://nodejs.org** → кнопка «LTS». Вместе с Node.js ставится и `npm`.

Проверить, что всё установлено (в терминале: на Windows — «Командная строка» или PowerShell,
на macOS — «Терминал»):

```bash
node -v    # должно быть v20.19.0+ или v22.12.0+ (например, v24.x.x)
npm -v     # любая версия 10+ (идёт вместе с Node.js)
```

Если команда `node` не найдена — перезапустите терминал (или компьютер) после установки Node.js.

**Git** — по желанию. Без Git можно скачать проект архивом: на странице репозитория на GitHub
нажмите **Code → Download ZIP** и распакуйте его.

### 2. Запуск по шагам

```bash
git clone https://github.com/linee64/vibe-app.git   # или скачайте и распакуйте ZIP
cd vibe-app                                           # для ZIP папка может называться vibe-app-main
npm install                                           # один раз: скачает зависимости (1–2 минуты)
npm run dev                                           # запуск dev-сервера
```

Вместо `npm install` можно использовать `npm ci` — он ставит ровно те версии, что записаны в `package-lock.json`.

Когда в терминале появится строка `Local: http://localhost:5173/`, откройте в браузере
**http://localhost:5173**. Это лендинг; нажмите «Начать бесплатно» или «Войти»
и введите **любой email** (например, `me@example.com`) и **любой непустой пароль** — вход тестовый,
ничего никуда не отправляется.

### 3. Остановка и другие команды

Остановить сервер: в окне терминала нажмите **Ctrl+C** (на macOS тоже Ctrl+C; на Windows может спросить
«Terminate batch job (Y/N)?» — ответьте `Y`).

```bash
npm run dev       # dev-сервер с автообновлением на http://localhost:5173
npm run build     # проверка типов TypeScript + production-сборка в папку dist/
npm run preview   # раздача собранной версии (после build) на http://localhost:4173
npm run lint      # проверка кода линтером oxlint
npm test          # unit-тесты (vitest): /api, слияние прогресса, мост ИИ → симулятор
vercel dev        # сайт + функции /api вместе на http://localhost:3000 (нужен .env.local, см. SETUP.md)
```

### 4. Если что-то пошло не так

- **Порт 5173 занят.** Vite сам возьмёт следующий свободный (5174, 5175…) — смотрите адрес в строке `Local:`.
  Чтобы задать порт явно: `npm run dev -- --port 3000`.
- **Ошибка про версию Node.js** (например, `Vite requires Node.js version 20.19+ or 22.12+`,
  `Unsupported engine` или непонятные ошибки синтаксиса при запуске). Обновите Node.js до LTS с https://nodejs.org,
  откройте новый терминал, удалите папку `node_modules` и снова выполните `npm install`.
- **`npm install` завершился с ошибкой.** Проверьте интернет/VPN/прокси, затем удалите папку `node_modules`
  (файл `package-lock.json` **не трогайте**) и повторите `npm install`. Если не помогло — `npm cache verify`
  и ещё раз `npm install`.
- **Windows PowerShell: «выполнение сценариев отключено в этой системе» / `running scripts is disabled`.**
  Запустите команды в обычной «Командной строке» (cmd), либо один раз разрешите локальные скрипты в PowerShell:
  `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` (ответьте `Y`).
- **Открыть на телефоне.** Телефон и компьютер должны быть в одной Wi‑Fi сети. В `vite.config.ts` уже включён
  `server.host`, поэтому `npm run dev` сразу печатает строку `Network:` (вида `http://192.168.x.x:5173`) — откройте
  этот адрес на телефоне. (В проектах без этой настройки то же делает `npm run dev -- --host`.)
  Если не открывается — разрешите Node.js доступ к сети в брандмауэре (Windows спросит при первом запуске).
- **Сбросить прогресс.** Профиль → «Сбросить демо-прогресс», или «Выйти», или очистите данные сайта
  `localhost:5173` в браузере (DevTools → Application → Local Storage → удалить ключи `vaibik.*`).
- **Playwright не нужен для `npm run dev`.** Он используется только скриптами скриншотов и проверок из `scripts/`.
  Браузер для них ставится отдельно: `npx playwright install chromium`.

## Демо-режим и настоящий режим

Режим выбирается **только переменными окружения** (список и пояснения — в `.env.example`, инструкция — в `SETUP.md`):

| | Демо (ничего не задано) | С переменными |
|---|---|---|
| Вход | любой email и непустой пароль, всё в `localStorage` | Supabase: регистрация, вход, сброс пароля по почте |
| Прогресс | `localStorage` (`vaibik.progress`) | тот же стор + синхронизация в таблицу `progress` (слияние «ничего не теряем») |
| Домашки | офлайн-симуляция ИИ | DeepSeek через `/api/ai/review`: советы Бипи, улучшенный промпт; при ошибке или лимите — симуляция |
| Оплата | кнопки «скоро» | Polar: пробные 3 дня, пейвол разделов 2–5, «Управлять подпиской» в профиле |
| Аналитика | выключена (в dev — лог в консоль) | PostHog: воронка событий без личных данных (`docs/analytics.md`) |
| Ошибки | экран «Бипи споткнулся» | + отчёты в Sentry (веб, `/api`, мобилка) с вычисткой секретов и PII |
| Отзывы | сохраняются в браузере, «Спасибо!» | `/api/feedback` → таблица `feedback` и/или Telegram/Discord/Slack |

`VITE_REVIEW_MODE` (по умолчанию `true`) — режим ревью: все тиры открыты, пейвола нет. **Перед запуском — `false`.**

Тарифы — Free $0, Pro $9.99/мес или $59.99/год ≈ $5/мес, 3 дня бесплатно (USD, глобальный рынок),
обоснование — в `docs/pricing-research.md`. Бесплатно навсегда — раздел 1 (с домашкой) и «Тест на уровень».
Все пользователи рейтинга, лиги и стартовый прогресс демо-режима — **демо-данные**.

### Где что лежит (бэкенд)

- `api/` — Vercel Functions (Node): `ai/review`, `billing/checkout`, `billing/portal`, `billing/webhook`, `feedback`, `health`.
- `server/` — их логика (проверка токена, лимиты, DeepSeek, Polar, подпись вебхуков, отзывы и rate limit,
  мини-клиент Sentry `server/sentry.ts`); тесты — `tests/api/`.
- `supabase/migrations/0001_init.sql` — таблицы, RLS, триггер профиля, функции лимитов и подписок;
  `0002_feedback.sql` — таблица отзывов (RLS: ученик видит только свои). Проверка RLS локально — `supabase/tests/`.
- `src/lib/` — клиент: конфиг по env, Supabase, вход, синхронизация, `reviewPrompt()`, подписка,
  `analytics.ts` (PostHog, лениво), `sentry.ts` (лениво), `feedback.ts`, `scrub.ts` (вычистка PII).
- `src/homework/ai.ts` — перевод ответа ИИ на язык симуляторов превью.

## Отзывы, аналитика, ошибки

- **«Отзыв»** — в профиле, в боковом меню (на телефоне — иконка в шапке), в «Ещё» и в подвале лендинга:
  оценка лицами Бипи (1–5), темы Баг / Идея / Сложно, непонятно / Другое, текст до 1000 символов, почта для гостей,
  переключатель «Приложим технические детали» (экран, урок, версия, браузер — без личных данных).
- **Микро-опросы** — по одному, не чаще раза в сутки, закрываются крестиком, никогда во время урока:
  после первого пройденного урока, после сданной домашки и после закрытия пейвола без покупки («Что остановило?»).
- **Аналитика** — PostHog, только с `VITE_POSTHOG_KEY`; список событий и воронка — `docs/analytics.md`.
- **Ошибки** — экран «Прости, Бипи споткнулся» с кнопкой «Перезагрузить»; с `VITE_SENTRY_DSN` — отчёт в Sentry.
  Проверить: `localStorage.setItem('vaibik.debug','1')` → `#/debug/crash`.

## Экраны

- `/` — публичный лендинг для гостей (вошедших сразу ведёт в `#/learn`); `#/landing` — лендинг всегда; `#/pricing` — лендинг сразу на тарифах (туда ведёт карточка Pro в профиле)
- `#/login` — вход (валидация email/пароля, «Создать аккаунт» показывает тост)
- `#/learn` — путь обучения: **3 тира** (Новичок · Средний · Продвинутый) с большими баннерами, внутри — **5 разделов**
  (5 уроков + домашка + итоговый тест в каждом, «змейкой»), тизер «Скоро: ИИ-агенты, Оплата в своём приложении»,
  правая колонка со статистикой и заданиями. После первого входа — необязательное предложение пройти «Тест на уровень»
- `#/lesson/<id>` — урок: 8 фирменных типов упражнений (см. ниже), заряд Бипи, подсказка за токены, обратная связь с объяснением
- экран «Урок пройден» — вайб-поинты, токены, точность, время; «Продолжить» возвращает на путь и прокручивает к пройденному уроку
- `#/homework/<hw1…hw5>` — **«Домашка»**: мини-проект раздела на весь экран (см. ниже); экран «Домашка сдана!» — +50 ВП и значок
- `#/placement/<mid|pro>` — **«Тест на уровень»**: 8 вопросов (те же типы упражнений) из предыдущих тиров; заряд Бипи не тратится;
  6+ верных — тир открывается сразу, пропущенные тиры отмечаются «засчитан тестом»
- `#/tier-up/<tier>` — праздничный экран «Тир пройден!» (показывается один раз на тир)
- `#/leaderboard`, `#/profile` — облегчённые экраны (в профиле — текущий тир, домашки, ссылка на свой проект,
  «Сбросить демо-прогресс» и **«Разблокировать всё (демо)»**); `#/quests`, `#/more` — заглушки «Скоро»

## Упражнения

Вместо универсальных «выбери вариант / собери из кусочков» у Вайбика свои типы — каждый со своей рамкой.
Данные — `src/data/units/u1…u5-*.ts`, типы — `src/data/types.ts`, проверка и перемешивание — `src/data/exerciseLogic.ts`,
отрисовка — `src/components/exercises/`. В каждом уроке не меньше трёх разных типов, «Ситуаций» — не больше четверти.

| Тип | Что делает ученик |
|-----|-------------------|
| ⚔️ Дуэль промптов | Два промпта и то, что по ним выдал ИИ: выбрать победителя, потом причину |
| 🔮 Предскажи результат | Промпт (иногда с кодом) — какой из результатов выдаст ИИ |
| 🎛️ Прокачай промпт | Слабый промпт + чипы-улучшения и чипы-ловушки; Вайб-метр растёт и проседает |
| 💬 Следующий ход | Диалог с ИИ уже начат — какое сообщение отправить следующим |
| 🔍 Ревью правок ИИ | Дифф от ИИ: принять или отклонить каждый кусок (бирюзовый/коралловый, без зелёного и красного) |
| 🐞 Найди баг | Строка с багом в коде от ИИ; режим «🚩 Красный флаг» — неверная фраза в тексте ИИ |
| 🛤️ Собери пайплайн | Карточки шагов на трек по порядку (тап или перетаскивание), одна-две лишние |
| 🧭 Ситуация | Карточка-сценарий «что сделаешь?» — не больше 25% упражнений |

- У каждого упражнения есть объяснение «почему». В данных правильный вариант пишется первым —
  перед показом варианты детерминированно перемешиваются (`prepareExercise`), так что позиции ответов сбалансированы.
- У «Прокачай промпт» ровно одно решение: все хорошие чипы нужны (без любого цель недостижима), ловушка всегда снижает Вайб-метр и не засчитывается.
- **Подсказка Бипи** — 10 токенов: вычёркивает неверный вариант, помечает ловушку, безопасную правку или первый шаг пайплайна.

## Экономика

Своя, без «жизней» и «кристаллов». Имена полей в сохранении не менялись (`hearts`, `gems`, `streak`, `xp`),
поэтому облачная синхронизация и старые сохранения работают как раньше — изменились смысл и вид.

| На экране | Поле | Как работает |
|-----------|------|--------------|
| Заряд Бипи (батарейка, 5 делений) | `hearts` | Ошибка тратит деление — это пауза, не штраф. +1 деление каждые 20 минут (`vaibik.chargeAt`, только локально), +1 за исправленную ошибку и за разбор ошибки в модалке «Бипи на нуле» |
| Токены | `gems` | За уроки (+5, без ошибок +10). Тратятся на подсказку (10) и полную подзарядку (30). Мини-магазин — по нажатию на счётчик токенов |
| Деплой-серия | `streak` | Дни подряд с уроками |
| Вайб-поинты (ВП) | `xp` | Очки за уроки и домашки |

## Домашки — мини-проекты с симулированным ИИ

В конце каждого раздела (перед итоговым тестом) — узел-домик «Домашка». Слева — задание, чек-лист требований (отмечается вживую)
и подсказки Бипи; в центре — чат с ИИ: промпт пишется в поле и/или собирается из цветных блоков (роль, цель, контекст, секции,
стиль…), есть уточняющие подсказки («Сделай кнопку коралловой»); справа — **живое превью** результата.
ИИ **симулирован** (`src/homework/sims.ts`): детерминированный разбор промпта по ключевым словам, без API и интернета. Расплывчатый
промпт даёт посредственный результат и разбор от Бипи, уточнения меняют только то, о чём попросили.

| # | Домашка | Что проверяет чек-лист |
|---|---------|------------------------|
| 1 | Карточка товара (термокружка) | в промпте есть роль, цель, контекст, ограничения и формат; превью карточки и «качество ответа» растут |
| 2 | Лендинг кофейни «Зерно» | первый экран с названием, меню с ценами, кнопка брони, свои цвета, адаптив + просмотр в режиме «Телефон» |
| 3 | Почини список дел | в промпте текст ошибки из консоли, файл/функция, код функции, шаги и ожидание; потом добавить задачу в починенном превью |
| 4 | Форма отзывов + таблица | поля имя/email/сообщение, сохранение в таблицу, валидация, ключ в `.env` (вставленный ключ — тревога!), тестовая запись в таблице |
| 5 | Запуск в сеть | коммит с понятным сообщением → push на GitHub → деплой на Vercel → свой домен → аналитика; пропуск шага ломает цепочку. Можно сохранить ссылку на свой настоящий проект (только в `localStorage`) |

Данные домашек — `src/data/homework.ts`, превью — `src/homework/previews.tsx`, экран — `src/screens/Homework.tsx`.

## Тиры и блокировки

- Новичок = разделы 1–2, Средний = 3–4, Продвинутый = 5 (`src/data/tiers.ts`).
- Тир открыт, когда пройден предыдущий: сданы **итоговые тесты и домашки** всех его разделов (у Новичка — 4 задания)
  или он **засчитан «Тестом на уровень»**. Внутри открытого тира все узлы доступны, как раньше.
- Узлы закрытого тира серые с замком; по нажатию — «Заверши тир Новичок, чтобы открыть» с прогрессом и кнопкой теста.
  Прямые ссылки на уроки/домашки закрытого тира показывают экран «Тир пока закрыт».
- Демо: «Профиль → Разблокировать всё (демо)» снимает блокировки (кнопка рядом со сбросом прогресса; повторное нажатие возвращает их).
  В скриптах — `unlockAll(page)` из `scripts/lib/vibe.mjs`.

## Скрипты проверки и скриншоты

Нужен Playwright с браузером: `npx playwright install chromium` (один раз). Сначала запустите `npm run dev` в отдельном терминале.

```bash
node scripts/playthrough.mjs             # 375px: блокировки тиров и «Тест на уровень», затем ВСЕ 30 уроков + 5 домашек по порядку
                                         # (ошибки разных типов упражнений, заряд «Бипи на нуле» → разбор), «Разблокировать всё», экономика; переполнение и ошибки консоли
node scripts/playthrough.mjs http://localhost:5173 --desktop   # то же на 1280px
node scripts/screenshots.mjs             # экраны приложения → ./screenshots/01…07-*.png
node scripts/path-shots.mjs              # путь из 5 разделов (с «Разблокировать всё») и уроки разделов 4–5 → ./screenshots/20…25-*.png
node scripts/landing-shots.mjs           # лендинг → ./screenshots/10…13-landing-*.png
node scripts/pricing-shots.mjs           # тарифы и FAQ → ./screenshots/14…16-*.png
node scripts/homework-shots.mjs          # тиры, попап закрытого узла, тест на уровень, 5 домашек, мобильная домашка, «Тир пройден!» → ./screenshots/30…39-*.png
```
