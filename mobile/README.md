# Вайбик — мобильное приложение

React Native-версия курса «Вайбик» (Expo SDK 57, expo-router). Веб-приложение в корне репозитория не меняется: контент курса, логика упражнений, экономика, тарифы и симуляторы домашек берутся напрямую из `../src` (один источник правды, см. `metro.config.js`).

## Требования

- **Node.js 22.13+, 24.3+ или 26+** (React Native 0.86). На машине разработки проверено на Node 24.21.
- Телефон с **Expo Go** (для демо-режима) или dev build (для покупок RevenueCat).

## Запуск

```bash
cd mobile
npm install
npx expo start
```

В терминале появится QR-код: открой его приложением Expo Go (Android — прямо из Expo Go, iOS — камерой). Приложение запустится в **демо-режиме**: вход по любому email, прогресс в AsyncStorage на устройстве, ИИ-проверка домашек — офлайн-симуляция, оплата — демо-пейвол без списаний.

Чтобы смотреть в браузере: `npx expo start --web`.

## Что внутри

- Путь из 5 разделов и 3 тиров (Новичок / Средний / Продвинутый), тест на уровень.
- Все 8 типов упражнений: дуэль промптов, предскажи результат, прокачай промпт с Вайб-метром, следующий ход, ревью правок, найди баг / красный флаг, пайплайн, ситуация.
- Экономика: заряд Бипи (батарейка, +1 деление / 20 мин), токены и магазин, деплой-серия, вайб-поинты. Экран «Бипи на нуле» с разбором ошибки.
- 5 домашек с нативным превью и чек-листом; ИИ-проверка — через бэкенд веба (`POST {EXPO_PUBLIC_API_BASE}/api/ai/review`), иначе симуляция.
- Профиль, лига (демо-таблица), пейвол Pro.
- «Отзыв» (профиль и иконка в шапке пути): лица Бипи 1–5, темы, текст, почта для гостей, тех. детали по желанию; микро-опросы после первого урока, домашки и закрытия пейвола.
- PostHog (`posthog-react-native`) и Sentry (`@sentry/react-native`) — только при `EXPO_PUBLIC_*` ключах; при падении экрана — «Прости, Бипи споткнулся» с кнопкой «Перезагрузить».

Прогресс хранится под ключом `vaibik.progress` в той же форме, что и веб-версия, поэтому строка в Supabase совместима.
